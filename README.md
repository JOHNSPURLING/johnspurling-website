# johnspurling-website

Official website for John Spurling at `johnspurling.co.uk`.

## Stack

- Vinext
- React
- TypeScript
- Tailwind CSS
- OpenAI Sites Vite plugin

## Local Development

```bash
pnpm install
pnpm run dev
pnpm run build
pnpm test
```

If the default shell does not expose Node, use the bundled Codex runtime path
documented in `AGENTS.md`.

## Content Notes

- Main homepage content is driven from `app/data/site-content.ts`.
- Migration planning from the existing OH-BEHAVE site is in `CONTENT-MIGRATION.md`.
- Do not add unconfirmed personal biography, social links, contact details,
  credentials, testimonials or client names.
